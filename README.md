# Netflix Data Analysis using Python

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset to identify trends in content type, release year, and sentiment distribution. The analysis helps understand how Netflix content has evolved over time.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Plotly
- Jupyter Notebook

## Dataset

- Source: Kaggle (Netflix Movies and TV Shows dataset)
- Records include movies and TV shows with details such as title, release year, genre, country, and description.

## Key Analysis Performed

- Movies vs TV Shows distribution
- Top 5 casts of Netflix
- Top 5 directors
- Number of releases per year (trend analysis)
- Content growth since 2000
- Sentiment analysis of content descriptions

## Visualizations

- Line charts for yearly releases
- Bar charts for top 5 directors and top 5 casts
- Sentiment trends over years
- Interactive Plotly charts for better insights
